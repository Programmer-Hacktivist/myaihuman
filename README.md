# 🧠 MY AI HUMAN — Advanced AI Agent System

An advanced **AI voice assistant + autonomous PC control system** powered by LLMs, voice recognition, and computer vision.

---

## 🚀 Features

- 🎙️ Voice-controlled AI assistant
- 🌍 Multilingual support (English, Hindi, auto-detect)
- 👁️ Face recognition security system
- 🧠 AI agent reasoning (Groq / LLM-based)
- 🖥️ Full PC automation (apps, scripts, browser)
- 🔊 Smart alert system (tiered security levels)
- 🧠 Memory system (context-aware assistant)

---

## 🧠 Architecture

- LLM Brain → decision making
- Voice Engine → speech input/output
- Vision Module → face recognition
- Controller → system automation
